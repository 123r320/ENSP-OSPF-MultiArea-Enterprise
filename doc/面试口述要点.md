# OSPF 知识点与面试口述要点

## 1. OSPF LSA 类型

Type1：路由器 LSA，每台路由器都会产生，用来描述自己所在区域内的直连链路信息，只在当前区域内泛洪。

Type2：网络 LSA，由 DR 产生，用于描述广播型网络中的网段信息，只在当前区域内泛洪。

Type3：网络汇总 LSA，由 ABR 产生，用于把一个区域的路由信息传递给其他区域，本项目中跨区域路由主要依靠 Type3 LSA 传递。

Type4 和 Type5：与外部路由有关。本项目没有引入外部路由，所以不涉及 Type4 和 Type5。

## 2. DR/BDR 选举

DR 和 BDR 只在广播型网络中选举，以太网中会选举，点到点链路不选举。

选举规则：首先比较接口优先级，优先级越高越容易当选；如果优先级相同，则比较 Router-ID，Router-ID 越大越优先。

接口优先级为 0 时，表示不参与 DR/BDR 选举，只能成为 DRother。

DR/BDR 的作用是减少邻接关系数量，降低 LSA 泛洪规模。DRother 只和 DR、BDR 建立 Full 邻接关系，DRother 之间保持 2-way 状态。

## 3. 多区域 OSPF 防环原理

第一，Area0 是骨干区域，是整个 OSPF 网络的核心。所有非骨干区域都必须直接连接 Area0，区域之间的路由信息必须经过骨干区域中转。

第二，ABR 不会把从其他区域学到的 Type1 和 Type2 LSA 再回传给原来的区域。

第三，Type3 汇总 LSA 携带区域信息，路由器可以根据区域信息判断路由来源，避免区域间环路。

注意：多区域 OSPF 主要防止区域间环路，区域内部环路依靠 SPF 算法防止。

## 4. 路由汇总优缺点

优点：

第一，可以减少骨干区域的 LSA 数量，减小 LSDB 规模，降低路由器 CPU 和内存负担。

第二，某个分支网段出现故障时，如果明细路由消失，但汇总路由仍然存在，故障影响不会扩散到整个网络，网络稳定性更好。

缺点：

第一，可能产生路由黑洞，因为明细路由失效后，汇总路由可能仍然存在。

第二，汇总后路由条目变粗，不方便针对具体网段做精细路由策略和流量控制。

第三，ABR 汇总只能汇总自己所在区域内的路由，不能汇总外部路由。

## 5. Silent-interface 静默接口原理

静默接口不会发送 OSPF Hello 报文，也不能建立 OSPF 邻居关系。但是该接口所在网段仍然可以被 OSPF 宣告进 LSDB，其他路由器仍然可以学习到这个网段的路由。

静默接口适用于连接终端的接口，比如下联 PC 的接口。因为终端不需要和路由器建立 OSPF 邻居，配置静默接口可以减少不必要的 OSPF 报文。

## 6. 本项目面试口述要点

本项目是一个基于 eNSP 的多区域 OSPF 实验，模拟企业内网组网。网络中存在 Area0 骨干区域，以及 Area1 和 Area2 两个非骨干区域。所有区域之间的路由信息都必须经过 Area0 中转。

IP 规划方面，路由器之间的互联地址使用 10.0.0.0 段，终端业务地址使用 192.168.0.0 段。每台路由器手动配置 Router-ID，保证设备身份稳定。接口先开启，再配置 IP 地址，然后在 OSPF 中宣告对应网段。二层交换机只负责二层转发，不需要配置 IP 地址，也不需要运行 OSPF。

配置完成后，通过 display ospf peer 查看邻居状态，通过 display ip routing-table protocol ospf 查看路由表，最后用 PC 互 ping 验证全网互通。

实验中也做了故障模拟。比如接口被 shutdown，导致邻居无法建立；网段宣告错误，导致路由学习不到；区域配置不一致，导致邻居无法正常建立。排障顺序一般是先检查接口状态，再检查 IP 地址，然后检查 OSPF 邻居，最后检查路由表和区域配置。

通过这个项目，我理解了 OSPF 多区域的基本原理。Area0 是核心，非骨干区域必须连接 Area0。Type1 和 Type2 LSA 在区域内泛洪，Type3 LSA 负责跨区域传递路由。配置路由汇总可以减少 LSA 数量，提升稳定性，但也可能带来路由黑洞问题。静默接口可以用于连接终端的接口，防止终端收到不必要的 OSPF 报文。
