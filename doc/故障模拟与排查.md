\# 故障模拟与排查

本项目设计3个故障场景，用于练习OSPF排障，面试重点内容。



\## 故障1：OSPF接口宣告区域错误

\### 故障现象

R2和R1的OSPF邻居无法建立，邻居状态停留在Init状态，无法到达Full。分支网段路由无法学习。

\### 故障原因

R2连接R1的G0/0/1接口，错误宣告进Area0，正确应该宣告进Area1。OSPF邻居建立要求直连接口两端OSPF区域号必须一致。

\### 排查步骤

1\. `display ospf peer brief` 查看邻居状态，发现状态卡在Init

2\. `display ospf interface GigabitEthernet0/0/1` 查看该接口所属OSPF区域

3\. 对比R1、R2两端接口OSPF区域，发现区域号不一致

\### 修复命令

修改R2，将互联接口宣告回Area1，邻居状态变为Full。



\## 故障2：取消ABR路由汇总

\### 故障现象

骨干区域Area0的LSDB条目大量增加，出现分支网段明细路由，路由器LSDB开销变大。

\### 故障原因

R1作为ABR删除abr-summary汇总命令，不再生成汇总Type3 LSA，分支明细LSA全部泛洪进入骨干Area0。

\### 排查步骤

1\. `display ospf lsdb` 在R1查看LSDB，观察LSA数量

2\. 在R1查看OSPF区域配置，确认abr-summary是否配置

\### 修复命令

```



ospf 1

area 1

abr-summary 192.168.20.0 255.255.255.0

area 2

abr-summary 192.168.30.0 255.255.255.0



```



\## 故障3：修改接口cost，改变OSPF选路

\### 故障现象

路由表优选路径发生变化，开销值改变。

\### 原理

OSPF cost计算公式：`cost = 100M / 接口带宽`；cost在入方向计算，cost越小越优先。

\### 模拟操作

修改R1 G0/0/1接口cost：

```



interface GigabitEthernet0/0/1

ospf cost 100



```

\### 现象

该链路开销变大，优先级下降。

\### 排查

`display ip routing-table protocol ospf` 查看路由下一跳变化。
