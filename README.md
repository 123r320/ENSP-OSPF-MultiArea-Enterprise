##OSPF 多区域路由配置实验（eNSP）

##项目介绍

本项目在华为 eNSP 仿真软件中搭建 OSPF 多区域网络拓扑，使用 5 台 AR2220 路由器、3 台 LSW 二层交换机、3 台 PC 终端。
通过划分骨干区域 Area 0 与多个非骨干区域 Area1、Area2、Area3，完成 OSPF 多区域部署，实现三台 PC 之间全网互通。
本项目用于练习 OSPF 协议原理、ABR 区域边界路由器配置、OSPF 邻居建立、路由查看、故障排查，学习企业级网络多区域组网思路。

##实验环境

- 仿真软件：eNSP
- 设备清单：AR2220 路由器 ×5，LSW 二层交换机 ×3，PC 终端 ×3

##实验原理与总结

1. OSPF 协议是链路状态型内部网关路由协议，多区域组网时**必须有骨干区域 Area 0**，所有非骨干区域必须连接 Area0，非骨干区域之间不能直接相连。
2. ABR（区域边界路由器）：同时属于 Area0 和一个非骨干区域，负责在不同区域之间传递路由信息，本项目 AR1、AR2、AR3 为 ABR 路由器。
3. Router-ID：OSPF 路由器唯一标识，推荐手动配置，避免设备自动选举产生不稳定问题。
4. 二层交换机 LSW 只做二层数据帧转发，不需要 IP 地址、VLAN 配置，不需要 OSPF。
5. 排错思路：先确认接口`undo shutdown`开启、IP 地址配置无误；再确认接口宣告进正确 OSPF 区域；查看 OSPF 邻居是否建立；邻居正常后检查路由表，最后测试 PC 互通。
